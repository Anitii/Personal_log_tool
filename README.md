# 日常甘特

把 Excel 日常甘特圖做成網頁版，手機、平板、電腦都能用。純靜態網站，不需要伺服器和建置步驟，可以直接放上 GitHub Pages。

## 放上 GitHub Pages

1. 在 GitHub 建立一個新的 repository，例如 `daily-gantt`。
2. 把這個資料夾的所有檔案傳上去（網頁上傳或 `git push` 都可以）。`index.html` 要在 repository 的最上層。
3. 到 repository 的 **Settings → Pages**，在 **Build and deployment** 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 約一分鐘後就能開啟 `https://你的帳號.github.io/daily-gantt/`。

> 免費帳號的 GitHub Pages 需要公開的 repository。程式碼是公開的，但你的任務資料不在程式碼裡：資料只存在瀏覽器（和你選擇開啟的同步 Gist）。

## 第一次使用

- **匯入原本的 Excel**：到「設定 → 匯入 Excel 甘特圖」，選 `日常甘特圖模板_2026年10至12月.xlsx`。任務、專案清單和週次基準都會帶進來。重複匯入不會產生重複任務。
- **裝到手機主畫面**：iPhone／iPad 用 Safari 開啟後按「分享 → 加入主畫面」；Android 用 Chrome 的「安裝應用程式」。裝好後會全螢幕開啟，也能離線使用。

## 跨裝置同步（選用）

資料預設只存在目前這個瀏覽器。要讓所有裝置看到同一份：

1. 到 [GitHub 建立權杖](https://github.com/settings/tokens/new?scopes=gist&description=daily-gantt)，只勾 `gist`。
2. 在每台裝置的「設定 → 跨裝置同步」貼上一次。

資料會存成你帳號裡的一個秘密 Gist。修改後約 2.5 秒自動同步，離線時的修改會在連線後合併；同一個任務在兩台裝置都改過時，以較晚的修改為準。

安全須知：

- 秘密 Gist 不會出現在搜尋結果，但知道網址的人就能讀取，請不要存放機密資料。
- 權杖只存在該瀏覽器的 localStorage，不會傳到 GitHub 以外的地方。不過它能修改你帳號下的所有 Gist，請勿在共用電腦上使用，也建議設定到期日。

## 專案頁

點側邊欄的專案名稱（手機在「任務」頁點專案標題，或設定裡專案旁的資料夾圖示）就會進入那個專案的工作區：

- **總覽與進度**：整體完成度、逾期／進行中／未開始／已完成的數量、目標、截止日期（顯示還剩幾天）。
- **時程**：這個專案的任務色條、里程碑旗標、今天線和截止線，畫面多寬就畫多寬，不用左右捲。
- **里程碑**：名稱、日期、完成勾選；過期未完成的日期會變紅。
- **任務**：逾期的排最前面，可以直接勾選、展開子任務，或在最下面直接新增任務到這個專案。
- **連結**：專案相關的網址，可加名稱。任務內容裡的「連結與檔案」也可以放多個連結。
- **靈感筆記**：隨手記；連結 Google 後會自動存成雲端硬碟裡的一份 Google 文件，在 Google 文件裡改過的內容下次打開專案頁時會讀回來。
- **Google 雲端硬碟**：建立或連結專案資料夾，列出裡面的檔案，直接新增文件、試算表、簡報。任務可以從資料夾挑檔案附加，或貼上雲端硬碟連結。

雲端硬碟功能使用同一個 Apps Script，需要新版程式碼（設定 → Google 日曆 → 複製程式碼，貼回 Apps Script 後「管理部署作業 → 編輯 → 新版本」），並允許存取雲端硬碟。

## Google 日曆（選用）

連結後，Google 日曆的行程會出現在日時間表、週計畫和月曆上：

- 有時間的行程排在時間軸上，整天的行程列在週計畫的待辦上方、日時間表左邊的「Google 日曆」區塊。
- 點一下可以改名稱、日期、時間、地點、說明，或刪除；在時間軸上拖曳可以改時間或移到別天，拖下緣改長度。
- 別人主辦或唯讀日曆上的行程只能查看。重複行程在這裡的修改只影響那一次。
- 日時間表上自己排的時段，可以在時段內容裡按「移到 Google 日曆」。
- 「設定 → Google 日曆」可以選要顯示哪些日曆、新行程加到哪個日曆。

連線方式是你自己 Google 帳號裡的一小段 Apps Script，完全免費，不需要 Google Cloud 專案，也不用每小時重新登入。第一次設定（約 3 分鐘）：

1. 「設定 → Google 日曆」按「複製 Apps Script 程式碼」（或「查看程式碼」再自己複製）。
2. 到 [script.google.com](https://script.google.com/home/projects/create) 新增專案，貼上取代原本的內容並儲存。
3. 左側「服務」按 ＋，加入「Google Calendar API」。
4. 右上「部署 → 新增部署」，類型選「網頁應用程式」，執行身分「我」，存取權「所有人」，按部署。Google 會請你允許權限；畫面說應用程式未經驗證時，按「進階 → 前往（不安全）」，因為這是你自己寫的程式。
5. 把部署後的網址（`https://script.google.com/macros/s/…/exec`）貼回設定，按「連結」。

其他裝置：在已連結的裝置按「複製其他裝置用的連結碼」，貼到另一台裝置的同一個欄位。

安全須知：

- 程式碼裡有一組隨機密碼，Apps Script 只回應帶著這組密碼的要求。部署的存取權必須選「所有人」，工具才連得到，所以請不要分享程式碼或連結碼。
- 網址和密碼只存在各裝置的瀏覽器，不會進入跨裝置同步的 Gist。
- 要停用，到 script.google.com 刪除那個部署或專案即可。
- 改了 Apps Script 的程式碼後，要到「管理部署 → 編輯 → 版本選新版本」重新部署才會生效，網址不變。

## 與 Excel 版的對應

| Excel | 網頁版 |
| --- | --- |
| 每週總覽／每日甘特圖 | 「計畫」頁的「週／月」甘特圖，共用同一份資料，不必分開維護 |
| 狀態（自動） | 相同規則：已完成 → 已逾期 → 未開始 → 進行中，另有待填日期、日期錯誤 |
| 藍／綠／紫／橘色條、◆ 單日任務 | 相同的圖例，改為馬卡龍色，可在設定頁自訂 |
| 精簡模式 | 甘特圖 `⋯` 選單；螢幕較窄時自動精簡 |
| 專案設定、週次基準 | 設定頁 |
| 最多 30 列、到 1/3 為止 | 任務數不限，時間軸捲到盡頭會自動延伸 |

## 新增的任務細化功能

- **子任務**：每個任務可拆成多個子任務，各有自己的起訖日期、備註和順序，並在甘特圖上有自己的色條。
- **完成度自動計算**：有子任務時，勾選幾項就是幾成。
- **日期連動**：拖動任務時子任務一起移動；子任務超出範圍時任務自動變長；任務縮短時子任務會收進範圍內。
- **優先度、連結、備註**：任務內容面板可設定。
- **重複的子任務**：子任務可設成每天、每週指定星期或每隔幾天。它只會出現在符合的日子，每一天分開打勾，完成度依打勾的天數計算。「整個結束」會結束整個重複。
- **逾期的子任務**：過了結束日還沒完成的子任務，會一直留在今天頁、日時間表和週計畫的今天，直到勾選完成或改了日期。

## 計畫的四種檢視

| 檢視 | 用途 |
| --- | --- |
| 日 | 10 分鐘時間表加整天時間軸，安排今天幾點做什麼 |
| 週 | 週計畫手帳：每天上方是當天的待辦，下方是時間軸，與日時間表同步 |
| 甘特 | 甘特圖。雙指縮放（觸控板或觸控螢幕）調整時間範圍，放大時以天為單位，縮小時以週為單位；也可以用右上的 −／＋。最上面的「今天」整合今天要做的事，有子任務的任務以當天的子任務列出，可以直接勾選。每一列左邊的把手可以拖曳調整順序（子任務在同一個任務內調整）；右上的箭頭按鈕一次展開或收合全部子任務 |
| 月曆 | 上下捲動就能連續跨月，左右箭頭跳到上／下個月。有自己日期的子任務會以子任務顯示，任務當作它們的分類（顏色和星號跟著任務）；點日期可以在任務底下勾選當天的子任務。標星號的最明顯，其他預設變淡。雙指縮放可切換整月、3 週或 2 週 |

**週計畫**：拖動時段可移到別天或別的時間，拖下緣改長度；把待辦拖到時間軸上就排進那段時間；點空白處新增時段；點日期開啟那天的 10 分鐘時間表。

**日時間表左邊的「未歸檔的時段」**：沒有連到任務的時段（例如午餐）列在任務下方的虛線之後。可以把它從清單隱藏（時間表上仍在），或加入某個專案，成為新任務或某個任務的子任務。

**日、週的時間安排不會影響甘特圖和月曆。** 時間表上的時段是獨立的一層資料，只記得指向哪個任務。把任務排到 10–12 點、拖動或刪除時段，都不會改變任務的起訖日期、狀態和完成度。

- 排時間：把左邊的任務拖進表格；或點一下任務，再點或拖曳時段。手機上點任務後點時段最快，也可以長按再拖。
- 自由時段：點空白格，或在左下輸入名稱（例如午餐）。
- 調整：拖動時段可移動，拖末端可改長度。點時段可改時間、標記完成或刪除。
- 時段的「已完成」只代表這段時間做完了。要完成整個任務，請勾選任務，或用時段裡的「把整個任務標為完成」。

**可以拖曳的邊界**：甘特圖左邊任務欄的右邊界、週計畫待辦區下緣、日時間表左欄的右邊界，都可以拖曳調整大小，會記住設定；在邊界上點兩下恢復預設。

## 完成與封存

- 只有勾選完成（或在任務內容打開「已完成」）才算完成。完成度拉到 100%、或子任務全部勾完都不算；子任務全部勾完時，提示列會問要不要「標為完成」。
- 過了結束日還沒完成的任務算逾期，會排到清單和甘特圖的最上面。
- 已完成的任務會排到清單和甘特圖的最下面。
- 勾選完成時，提示列會多一個「封存」按鈕；任務頁的「封存已完成」能一次封存全部，任務內容面板也能封存。
- 封存的任務不會出現在今天、時間表、甘特圖和側邊欄計數；月曆上仍以淡色保留當時的紀錄，甘特圖 `⋯` 選單也能選擇顯示。
- 任務頁最下方的「已封存」可以展開查看，按「拉回來」就回到清單。
- 專案順序在設定頁用上下箭頭調整，側邊欄、篩選和分組都依這個順序，也會同步到其他裝置。

## 最重要的任務

在月曆點某一天，幫任務加上星號，就只標記那一天。優先度設為「高」的任務則每天都算最重要。可以用「淡化不重要」開關關閉淡化效果。

## 今天頁

- 現在與下一段時段、今天的時間軸、已排時數。
- 逾期任務可以一鍵改到今天或明天。
- 今天要做的事，加星號的排最上面，並直接顯示已該開始的子任務。
- 本週每天的任務量，點一天可開啟那天的時間表。
- 接下來 7 天到期的倒數。
- 一行快速記到今天的日記。

## 日記

每天一篇，內容以 Markdown 儲存。編輯方式參考 Notion：

- `/` 開啟選單，也能插入當天的時間表或任務。
- `# `、`## `、`### `、`- `、`1. `、`[] `、`> `、`---`、` ``` ` 會自動轉成對應的區塊，注音輸入的全形空白也可以。
- 工具列或快捷鍵套用格式：`Ctrl/⌘ + B` 粗體、`I` 斜體、`E` 行內程式碼、`K` 連結、`Shift + S` 刪除線。
- `Tab` 調整清單縮排，`Alt + ↑/↓` 上下移動區塊。
- 「Markdown」模式可以直接編輯原始內容。

按右上角的分享圖示可以匯出：選今天、本週、本月、全部或自訂範圍，勾選要的日子，下載 `.md` 或複製內容，也能一併輸出時間表。

同一天的日記在兩台裝置都改過時，整篇以較晚的修改為準。

## 顏色

設定頁可以改專案顏色和狀態顏色，任務內容面板可以幫單一任務指定顏色。除了馬卡龍色盤，彩色圓鈕能開啟系統的自訂顏色選擇器。甘特圖 `⋯` 選單可以改成依專案上色。

## 舊資料

新版沿用同一個儲存位置，打開就會自動升級。所有任務、子任務、專案和設定都會保留；舊版的鮮豔顏色會換成同色系的馬卡龍色，升級前的資料另外備份在瀏覽器的 `dg.data.before-v2`。

## 操作

- 甘特圖拖曳色條改日期，拖兩端改長度；手機和平板要**長按**色條再拖，一般滑動仍是捲動。
- 單日任務（◆）只能拖曳移動，要改成多天請開任務內容改結束日期。
- 大部分操作（刪除、完成、匯入）都能在提示出現時按「復原」。
- 鍵盤：`N` 新增任務、`1`–`5` 切換頁面、`T` 回到今天。

## 開發

介面規範寫在 `.claude/skills/ui-ux-foundations/SKILL.md`（視覺層級、版面網格、表格對齊、甘特圖色條名稱等），改畫面前後都用它的檢查表核對。

```bash
python -m http.server 5190   # 開啟 http://localhost:5190
```

```bash
npm test                     # 單元測試，不需安裝任何套件
```

`js/core.js` 和 `js/markdown.js` 只放純邏輯；`js/store.js` 管理資料；`js/views.js`、`js/gantt.js`、`js/planner.js`、`js/calendar.js`、`js/diary.js`、`js/sheet.js` 是畫面；`js/sync.js` 是 Gist 同步；`js/xlsx.js` 只在匯入時載入。

**更新已上線的網站時**：修改任何檔案後，都要把 `sw.js` 裡的 `VERSION` 改掉（例如 `v2` → `v3`），已安裝的裝置才會收到新版。
