# 日常甘特

把 Excel 日常甘特圖做成網頁版，手機、平板、電腦都能用。純靜態網站，不需要伺服器和建置步驟，可以直接放上 GitHub Pages。

## 放上 GitHub Pages

1. 在 GitHub 建立一個新的 repository，例如 `daily-gantt`。
2. 把這個資料夾的所有檔案傳上去（網頁上傳或 `git push` 都可以）。`index.html` 要在 repository 的最上層。
3. 到 repository 的 **Settings → Pages**，在 **Build and deployment** 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 約一分鐘後就能開啟 `https://你的帳號.github.io/daily-gantt/`。

> 免費帳號的 GitHub Pages 需要公開的 repository。程式碼是公開的，但你的任務資料不在程式碼裡：資料只存在瀏覽器（和你選擇開啟的同步 Gist）。

## 第一次使用

- **匯入原本的 Excel**：到「設定 → 匯入 Excel 甘特圖」，選 `日常甘特圖模板_2026年10至12月.xlsx`。任務、專案清單和週次基準都會帶進來。重複匯入不會產生重複任務。
- **裝到手機主畫面**：iPhone／iPad 用 Safari 開啟後按「分享 → 加入主畫面」；Android 用 Chrome 的「安裝應用程式」。裝好後會全螢幕開啟，也能離線使用。

## 跨裝置同步（選用）

資料預設只存在目前這個瀏覽器。要讓所有裝置看到同一份：

1. 到 [GitHub 建立權杖](https://github.com/settings/tokens/new?scopes=gist&description=daily-gantt)，只勾 `gist`。
2. 在每台裝置的「設定 → 跨裝置同步」貼上一次。

資料會存成你帳號裡的一個秘密 Gist。修改後約 2.5 秒自動同步，離線時的修改會在連線後合併；同一個任務在兩台裝置都改過時，以較晚的修改為準。

安全須知：

- 秘密 Gist 不會出現在搜尋結果，但知道網址的人就能讀取，請不要存放機密資料。
- 權杖只存在該瀏覽器的 localStorage，不會傳到 GitHub 以外的地方。不過它能修改你帳號下的所有 Gist，請勿在共用電腦上使用，也建議設定到期日。

## 與 Excel 版的對應

| Excel | 網頁版 |
| --- | --- |
| 每週總覽／每日甘特圖 | 甘特圖的「日／週／月」刻度，共用同一份資料，不必分開維護 |
| 狀態（自動） | 相同規則：已完成 → 已逾期 → 未開始 → 進行中，另有待填日期、日期錯誤 |
| 藍／綠／紫／橘色條、◆ 單日任務 | 相同的圖例 |
| 精簡模式 | 甘特圖 `⋯` 選單；螢幕較窄時自動精簡 |
| 專案設定、週次基準 | 設定頁 |
| 最多 30 列、到 1/3 為止 | 任務數不限，時間軸捲到盡頭會自動延伸 |

## 新增的任務細化功能

- **子任務**：每個任務可拆成多個子任務，各有自己的起訖日期、備註和順序，並在甘特圖上有自己的色條。
- **完成度自動計算**：有子任務時，勾選幾項就是幾成。
- **日期連動**：拖動任務時子任務一起移動；子任務超出範圍時任務自動變長；任務縮短時子任務會收進範圍內。
- **優先度、連結、備註**：任務內容面板可設定。
- **「今天」頁**：列出已逾期、進行中與接下來 7 天的任務，並直接顯示已該開始的子任務。

## 操作

- 甘特圖拖曳色條改日期，拖兩端改長度；手機和平板要**長按**色條再拖，一般滑動仍是捲動。
- 單日任務（◆）只能拖曳移動，要改成多天請開任務內容改結束日期。
- 大部分操作（刪除、完成、匯入）都能在提示出現時按「復原」。
- 鍵盤：`N` 新增任務、`1`–`4` 切換頁面、`T` 回到今天。

## 開發

```bash
python -m http.server 5190   # 開啟 http://localhost:5190
```

```bash
npm test                     # 單元測試，不需安裝任何套件
```

`js/core.js` 只放純邏輯（日期、狀態、合併）；`js/store.js` 管理資料；`js/views.js`、`js/gantt.js`、`js/sheet.js` 是畫面；`js/sync.js` 是 Gist 同步；`js/xlsx.js` 只在匯入時載入。

**更新已上線的網站時**：修改任何檔案後，都要把 `sw.js` 裡的 `VERSION` 改掉（例如 `v1` → `v2`），已安裝的裝置才會收到新版。
