# 日常甘特

把 Excel 日常甘特圖做成網頁版，手機、平板、電腦都能用。純靜態網站，不需要伺服器和建置步驟，可以直接放上 GitHub Pages。

## 放上 GitHub Pages

1. 在 GitHub 建立一個新的 repository，例如 `daily-gantt`。
2. 把這個資料夾的所有檔案傳上去（網頁上傳或 `git push` 都可以）。`index.html` 要在 repository 的最上層。
3. 到 repository 的 **Settings → Pages**，在 **Build and deployment** 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 約一分鐘後就能開啟 `https://你的帳號.github.io/daily-gantt/`。

> 免費帳號的 GitHub Pages 需要公開的 repository。程式碼是公開的，但你的任務資料不在程式碼裡：資料只存在瀏覽器（和你選擇開啟的同步 Gist）。

## 第一次使用

- **匯入原本的 Excel**：到「設定 → 匯入 Excel 甘特圖」，選 `日常甘特圖模板_2026年10至12月.xlsx`。任務、專案清單和週次基準都會帶進來。重複匯入不會產生重複任務。
- **裝到手機主畫面**：iPhone／iPad 用 Safari 開啟後按「分享 → 加入主畫面」；Android 用 Chrome 的「安裝應用程式」。裝好後會全螢幕開啟，也能離線使用。

## 跨裝置同步（選用）

資料預設只存在目前這個瀏覽器。要讓所有裝置看到同一份：

1. 到 [GitHub 建立權杖](https://github.com/settings/tokens/new?scopes=gist&description=daily-gantt)，只勾 `gist`。
2. 在每台裝置的「設定 → 跨裝置同步」貼上一次。

資料會存成你帳號裡的一個秘密 Gist。修改後約 2.5 秒自動同步，離線時的修改會在連線後合併；同一個任務在兩台裝置都改過時，以較晚的修改為準。

安全須知：

- 秘密 Gist 不會出現在搜尋結果，但知道網址的人就能讀取，請不要存放機密資料。
- 權杖只存在該瀏覽器的 localStorage，不會傳到 GitHub 以外的地方。不過它能修改你帳號下的所有 Gist，請勿在共用電腦上使用，也建議設定到期日。

## 與 Excel 版的對應

| Excel | 網頁版 |
| --- | --- |
| 每週總覽／每日甘特圖 | 「計畫」頁的「週／月」甘特圖，共用同一份資料，不必分開維護 |
| 狀態（自動） | 相同規則：已完成 → 已逾期 → 未開始 → 進行中，另有待填日期、日期錯誤 |
| 藍／綠／紫／橘色條、◆ 單日任務 | 相同的圖例，改為馬卡龍色，可在設定頁自訂 |
| 精簡模式 | 甘特圖 `⋯` 選單；螢幕較窄時自動精簡 |
| 專案設定、週次基準 | 設定頁 |
| 最多 30 列、到 1/3 為止 | 任務數不限，時間軸捲到盡頭會自動延伸 |

## 新增的任務細化功能

- **子任務**：每個任務可拆成多個子任務，各有自己的起訖日期、備註和順序，並在甘特圖上有自己的色條。
- **完成度自動計算**：有子任務時，勾選幾項就是幾成。
- **日期連動**：拖動任務時子任務一起移動；子任務超出範圍時任務自動變長；任務縮短時子任務會收進範圍內。
- **優先度、連結、備註**：任務內容面板可設定。

## 計畫的四種檢視

| 檢視 | 用途 |
| --- | --- |
| 日 | 10 分鐘時間表加整天時間軸，安排今天幾點做什麼 |
| 週 | 甘特圖，每欄一天 |
| 月 | 甘特圖，看整季的長條 |
| 月曆 | 一般月曆。標星號的任務最明顯，其他任務預設變淡 |

**日檢視不會影響週、月計畫。** 時間表上的時段是獨立的一層資料，只記得指向哪個任務。把任務排到 10–12 點、拖動或刪除時段，都不會改變任務的起訖日期、狀態和完成度。

- 排時間：把左邊的任務拖進表格；或點一下任務，再點或拖曳時段。手機上點任務後點時段最快，也可以長按再拖。
- 自由時段：點空白格，或在左下輸入名稱（例如午餐）。
- 調整：拖動時段可移動，拖末端可改長度。點時段可改時間、標記完成或刪除。
- 時段的「已完成」只代表這段時間做完了。要完成整個任務，請勾選任務，或用時段裡的「把整個任務標為完成」。

## 最重要的任務

在月曆點某一天，幫任務加上星號，就只標記那一天。優先度設為「高」的任務則每天都算最重要。可以用「淡化不重要」開關關閉淡化效果。

## 今天頁

- 現在與下一段時段、今天的時間軸、已排時數。
- 逾期任務可以一鍵改到今天或明天。
- 今天要做的事，加星號的排最上面，並直接顯示已該開始的子任務。
- 本週每天的任務量，點一天可開啟那天的時間表。
- 接下來 7 天到期的倒數。
- 一行快速記到今天的日記。

## 日記

每天一篇，內容以 Markdown 儲存。編輯方式參考 Notion：

- `/` 開啟選單，也能插入當天的時間表或任務。
- `# `、`## `、`### `、`- `、`1. `、`[] `、`> `、`---`、` ``` ` 會自動轉成對應的區塊，注音輸入的全形空白也可以。
- 工具列或快捷鍵套用格式：`Ctrl/⌘ + B` 粗體、`I` 斜體、`E` 行內程式碼、`K` 連結、`Shift + S` 刪除線。
- `Tab` 調整清單縮排，`Alt + ↑/↓` 上下移動區塊。
- 「Markdown」模式可以直接編輯原始內容。

按右上角的分享圖示可以匯出：選今天、本週、本月、全部或自訂範圍，勾選要的日子，下載 `.md` 或複製內容，也能一併輸出時間表。

同一天的日記在兩台裝置都改過時，整篇以較晚的修改為準。

## 顏色

設定頁可以改專案顏色和狀態顏色，任務內容面板可以幫單一任務指定顏色。除了馬卡龍色盤，彩色圓鈕能開啟系統的自訂顏色選擇器。甘特圖 `⋯` 選單可以改成依專案上色。

## 舊資料

新版沿用同一個儲存位置，打開就會自動升級。所有任務、子任務、專案和設定都會保留；舊版的鮮豔顏色會換成同色系的馬卡龍色，升級前的資料另外備份在瀏覽器的 `dg.data.before-v2`。

## 操作

- 甘特圖拖曳色條改日期，拖兩端改長度；手機和平板要**長按**色條再拖，一般滑動仍是捲動。
- 單日任務（◆）只能拖曳移動，要改成多天請開任務內容改結束日期。
- 大部分操作（刪除、完成、匯入）都能在提示出現時按「復原」。
- 鍵盤：`N` 新增任務、`1`–`5` 切換頁面、`T` 回到今天。

## 開發

```bash
python -m http.server 5190   # 開啟 http://localhost:5190
```

```bash
npm test                     # 單元測試，不需安裝任何套件
```

`js/core.js` 和 `js/markdown.js` 只放純邏輯；`js/store.js` 管理資料；`js/views.js`、`js/gantt.js`、`js/planner.js`、`js/calendar.js`、`js/diary.js`、`js/sheet.js` 是畫面；`js/sync.js` 是 Gist 同步；`js/xlsx.js` 只在匯入時載入。

**更新已上線的網站時**：修改任何檔案後，都要把 `sw.js` 裡的 `VERSION` 改掉（例如 `v2` → `v3`），已安裝的裝置才會收到新版。
